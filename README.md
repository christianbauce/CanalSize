How to install CanalSize from its GitHub page
1. Open the project page on GitHub: https://christianbauce.github.io/CanalSize/
2. Once the web app opens in your phone’s browser:
   - Android: open the page in Chrome, tap ⋮, then choose Install app or Add to Home screen. Confirm.
   - iPhone: open the page in Safari, tap Share, then Add to Home Screen. Confirm by tapping Add.
The CanalSize icon will appear on your phone’s home screen.

Use this link to add the app to your smartphone’s home screen or use it on your computer. However, this version is designed for smartphone use only.
